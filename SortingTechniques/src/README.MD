## Overview

Sorting algorithms arrange data in a specific order (ascending or descending). Efficient sorting is essential for optimizing searching and other algorithms, as well as for organizing data.

---

## Algorithms Summary

| Algorithm      | Time Complexity | Space Complexity | Stable | In-place | Best Use Case                    |
|----------------|----------------|------------------|--------|----------|----------------------------------|
| Bubble Sort    | $$O(N^2)$$     | $$O(1)$$         | Yes    | Yes      | Small or nearly sorted datasets  |
| Selection Sort | $$O(N^2)$$     | $$O(1)$$         | No     | Yes      | Simple, small datasets           |
| Insertion Sort | $$O(N^2)$$     | $$O(1)$$         | Yes    | Yes      | Small, nearly sorted datasets    |
| Cycle Sort     | $$O(N^2)$$     | $$O(1)$$         | No     | Yes      | Minimizing writes, special cases |
| Merge Sort     | $$O(N \log N)$$| $$O(N)$$         | Yes    | No       | Large datasets, stability needed |
| Quick Sort     | $$O(N \log N)$$ (avg), $$O(N^2)$$ (worst) | $$O(\log N)$$ | No | Yes | Fast, general-purpose sorting    |
