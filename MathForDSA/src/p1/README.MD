# Math for DSA (Data Structures and Algorithms)

This module covers essential mathematical concepts and algorithms that are frequently used in data structures and algorithms (DSA) problems. Each topic is explained with its working principle, time complexity, and practical Java implementation.

---

## Topics Covered

- **Sieve of Eratosthenes:**  
  Efficient algorithm to find all prime numbers in a given range.

- **Square Root Calculation:**  
  - Binary Search approach for integer and floating-point precision.
  - Newton-Raphson Method for fast square root approximation.

- **GCD (Greatest Common Divisor) / HCF (Highest Common Factor):**  
  Euclidean algorithm for finding GCD of two numbers.

- **LCM (Least Common Multiple):**  
  Formula-based calculation using GCD.

---

## File Overview

- **[MathForDSA.java](./MathForDSA.java):**  
  Contains implementations for all the above topics with sample usage in the `main` method.

---

## How to Use

- Refer to the code in [MathForDSA.java](./MathForDSA.java) for implementation details and example usage.
- Run the `main` method to see outputs for each mathematical function.
