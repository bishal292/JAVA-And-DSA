# Java OOPS Concepts

This module introduces the fundamental concepts of Object-Oriented Programming (OOPS) in Java, with practical examples and explanations. Each file in this directory covers a specific topic, helping you understand how Java implements OOPS principles.

---

## [OOPS_1.java](./OOPS_1.java) — Classes, Objects, Constructors, `this`, and `final` Keyword

- **Classes & Objects:**  
  Explains how classes serve as blueprints for objects, and how objects are instances of classes.
- **Constructors:**  
  Shows default and parameterized constructors, and how they initialize object state.
- **`this` Keyword:**  
  Demonstrates usage for referring to the current object.
- **`final` Keyword:**  
  Covers immutability for primitive and reference types, and how `final` affects variables and arrays.

---

## [OOPS_2.java](./OOPS_2.java) — Packages, Static Keyword, Blocks, In-built Methods

- **Packages:**  
  Difference between user-defined and predefined packages, and how to declare and use them.
- **Static Keyword:**  
  Explains static variables, methods, and blocks, and their behavior across objects.
- **Blocks:**  
  Shows static and instance blocks, their execution order, and purpose.
- **In-built Methods:**  
  Briefly mentions commonly used Java library methods.

---

## [OOPS_3.java](./OOPS_3.java) — Inner Classes and Static Inner Classes

- **Inner Classes:**  
  Explains regular (non-static) inner classes and their instantiation.
- **Static Inner Classes:**  
  Shows how static inner classes can be instantiated without an outer class object.
- **Syntax:**  
  Provides examples for creating objects of both types.

---

## [accessModifier](./accessModifier/README.MD) — Access Modifiers

- **Access Modifiers:**  
  Explains `private`, default (package-private), `protected`, and `public` modifiers.
- **Visibility Table:**  
  Shows where each modifier allows access (same class, package, subclass, etc.).
- **Practical Examples:**  
  See [A.java](./accessModifier/A.java) and [Main.java](./accessModifier/Main.java) for code demonstrating member accessibility.

- Explains how can we create a class in such way so that it can have exactly one object of it.
